# Downloads and offline sharing

> **In plain words**
>
> When the internet is slow, cut off or filtered, this plan still needs to reach people.
> From this page you can download the whole plan as one PDF, or each document separately.
> You can also download an offline copy of the whole site and open it on any phone or computer without internet.
> All of these files are free: copy them, share them, print them.

## Opening the offline copy

1. Download the ZIP file and extract it.
2. Open `index.html` in a browser.
3. All pages, links and search work without internet.

## Sharing safely

- **Messaging apps:** you can send the PDFs directly; remember that messaging apps may reveal the sender. See the [safe contribution guide](project/security.md).
- **USB sticks and memory cards:** the offline copy fits on a USB stick and can be passed hand to hand.
- **Authenticity:** anyone can alter a text and circulate it under this plan's name; the only authoritative version is the one in this repository.
