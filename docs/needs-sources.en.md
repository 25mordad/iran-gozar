# Claims awaiting a source

> **In plain words**
>
> This plan promised never to invent statistics or facts.
> Wherever we had no source, we wrote "citation needed" so that you can help.
> This page collects all of those places automatically.
> If you know a reliable source for one of them, open the document and use the "Fix this page" button to add it.

!!! tip "How do I add a source?"

    1. Open the document and find the "citation needed" marker.
    2. At the bottom of the page, click **"Fix this page"**.
    3. Remove `[citation needed]` and add the source to the "Sources" section: author or organization, title, year and, if possible, a link (ideally with an archived copy).
    4. If the source only supports part of the claim, change the text to match the source — not the other way round.

    Most documents are in Persian; the Persian list is much longer: [Persian list](https://25mordad.github.io/iran-gozar/needs-sources/).
